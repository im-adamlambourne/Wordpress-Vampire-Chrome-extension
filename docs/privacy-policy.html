Privacy Policy for Content Studio

Last updated: 9 September 2026

Content Studio is a Chrome extension published by Immediate Media Company Limited (“Immediate”, “we”) for Immediate Media staff. It helps editors revise an open WordPress draft from a chat overlay. Sign-in and settings live in the toolbar popup. Immediate Media Company Limited is the data controller for this product.

This policy describes what the extension stores on the device and what it sends to the Content Studio server (https://content-studio.im or https://develop.content-studio.im, or http://localhost if you save a local server in Settings). It is a staff tool. It is not affiliated with Automattic or WordPress.com.

Chrome Web Store Limited Use

We only collect, use, and share user data as needed for the extension’s single purpose: letting a signed-in editor revise the open WordPress draft from a chat overlay (title, selected copy, body, excerpt, SEO, Open Graph, and focus keyphrase), including operating, securing, and supporting those features.

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

See the Chrome Web Store Limited Use policy.

Content Studio sign-in uses your Immediate Media account, not a Google account. Chrome’s identity feature is used only to open that sign-in window and return you to the extension.

What data we collect

The extension processes the following data, only to run its features:

  • Account details. After you sign in, the extension stores your display name (or email if no name is returned) so the chat overlay can show your initials. It also stores an access token and a numeric user id for your Content Studio account so replies can be delivered on your private chat channel.
  • Server address. The Content Studio host you enter in Settings (https://content-studio.im, https://develop.content-studio.im, or a local http://localhost origin).
  • Chat and draft content. When you send a message, the extension sends that message, recent chat turns from the current editor page, and a snapshot of the open draft (title, body, excerpt, SEO and Open Graph text, focus keyphrase, and any selected copy) to your configured Content Studio server so it can reply and suggest edits.
  • Current browser tab. The extension reads the active tab’s address to detect whether you are on Immediate Media WordPress Cloud Platform admin (*.production.wcp.imdserve.com or *.release.wcp.imdserve.com), to show a connected or disconnected toolbar icon. It does not keep a browsing history.
  • Workspace features. The signed-in toolbar popup does not currently show Workspace buttons and does not request a Workspace catalog. A later build may show those buttons; if it does, the extension will ask Content Studio which sites and features you can use and may send the current tab address so the matching site is selected.
  • Device environment. When you send a chat message, the extension also sends the operating system name and version, the browser brand and version, and this extension’s version to your Content Studio server so support can tell which client you used. That data is not used for advertising.

The extension does not collect health or financial information, does not use advertising or analytics SDKs, and does not sell data. It does not sync extension storage through your Google account.

How data is stored

  • Host, access token, display name, user id, and public realtime connection settings returned at login (host, port, and app key — never the server secret) are stored in Chrome’s local extension storage on your computer. They are not synced through your Google account.
  • Short-lived login values (proof-of-login secrets, a one-time success message, and which editor tab is waiting for a chat reply) are stored in Chrome session storage and are cleared when you close the browser.
  • Chat transcripts stay in memory for the open editor page and are not written to disk by the extension.

How data is used

  • Sign you in to Content Studio and keep you signed in until you log out or the session expires.
  • Show your name or initials in the toolbar popup and chat overlay.
  • Send your prompt and draft snapshot to Content Studio so the assistant can suggest revisions.
  • Record the client operating system, browser, and extension version with each chat turn so Content Studio can support the plugin.
  • Apply suggested edits to the open WordPress editor. The extension does not save or publish the post.
  • Show a login-success notification after you connect your account.

Where data is sent

The extension sends data only to the Content Studio origin (https://content-studio.im or https://develop.content-studio.im, or http://localhost if you save a local server), after Chrome asks you to allow that origin, and to the realtime host that server returns when you sign in (locally a port on that same machine, otherwise a ws. hostname of the same site). Log in and Save host ask Chrome for that expected realtime origin before a token exists (localhost:8081, or ws. plus the hostname). Typical requests are:

  • Sign-in (authorization code exchange) and sign-out
  • Your profile name for the avatar
  • Chat messages, the draft snapshot, and device environment (OS, browser, and extension version) on the HTTP kick-off
  • A realtime connection so the assistant reply, suggested edits, and headline ideas can arrive without keeping a long HTTP request open
  • Channel authorization for that private chat connection

Content Studio may use AI providers to generate replies, headline ideas, related images, or backlinks. Those processors currently include OpenRouter and Google (Gemini). If you paste an http(s) URL in chat, Content Studio may retrieve that page through OpenRouter. The extension does not fetch third-party websites from your browser.

Successful chat turns are also recorded in Content Studio’s plugin usage log (your message, the assistant reply shown in the overlay, article URL, post id, which fields changed, assigned site, and device environment) so Immediate Media administrators can support the product. Full chat transcripts are not stored as a conversation history. Login and logout are logged the same way.

The extension does not send your draft or chat to advertisers, data brokers, or other unrelated parties. Chrome and Google do not receive your draft content from this extension.

Third-party services

Chrome provides the sign-in window, local storage, notifications, and a background page used only to keep the realtime connection alive. Application data is sent to Immediate Media’s Content Studio service and, when generating a reply, to these processors acting for Immediate:

  • OpenRouter (model routing and, if you paste a URL, fetching that page)
  • Google (Gemini model used to draft replies)

Immediate’s general privacy policy is at immediate.co.uk/privacy-policy-single-page. This page is specific to the Content Studio Chrome extension. There is no advertising network in the extension.

Data sharing

Immediate Media does not sell extension data. Draft and chat content is shared with the Content Studio service you connect to, and with the AI processors named above, so the assistant can do its job. It is not used for credit scoring, personalized advertising, or for purposes unrelated to editing the open draft and supporting the extension.

Data retention and deletion

  • Click the user icon next to Settings in the toolbar popup to log out. That removes the access token, display name, user id, and realtime settings from this browser. Changing the saved server host also clears those values.
  • Removing the extension from Chrome deletes its local storage.
  • Chat history on the editor page is discarded when you close or reload that tab.
  • How long Content Studio keeps server-side plugin usage logs is governed by Immediate Media’s internal retention rules for that service. You can ask us to delete personal data as described under Your rights.

Cookies

The Chrome extension does not use cookies. It stores settings and sign-in details in Chrome’s local and session extension storage as described above.

Permissions in plain language

  • Tabs — detect an Immediate Media WordPress Cloud Platform admin tab so the icon can show connected or disconnected.
  • Storage — remember your server, sign-in token, display name, user id, and realtime settings.
  • Identity — open the Content Studio sign-in window and return you to the extension.
  • Notifications — confirm a successful login after the sign-in window closes.
  • Offscreen documents — keep a quiet background page so chat replies can arrive after you send a message.
  • WordPress admin pages — show the revision overlay and read or update the open draft on Immediate Media WCP hosts (*.production.wcp.imdserve.com and *.release.wcp.imdserve.com) and local loopback.
  • Optional access to Content Studio — requested when you log in or save a host, so chat, login, and the realtime connection can reach https://content-studio.im, https://develop.content-studio.im, the matching ws. realtime host, or localhost (including port 8081). The extension does not request access to all websites.

Children

This product is for Immediate Media staff. It is not directed at children under 18, and we do not knowingly collect children’s personal data through it.
