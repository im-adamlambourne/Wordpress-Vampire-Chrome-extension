Privacy Policy for Content Studio Plugin

Last updated: 19 August 2026

Content Studio Plugin is a Chrome extension published by Immediate Media for staff use. It helps editors revise an open WordPress draft from a chat overlay. This policy describes what the extension stores on the device and what it sends to the Content Studio server you configure.

What data we collect

The extension processes the following data, only to run its features:

  • Account details. After you sign in, the extension stores your display name (or email if no name is returned) so the chat overlay can show your initials. It also stores an access token and a numeric user id for your Content Studio account so replies can be delivered on your private chat channel.
  • Server address. The Content Studio host you enter in Settings (for example a local, staging, or production origin).
  • Chat and draft content. When you send a message, the extension sends that message, recent chat turns from the current editor page, and a snapshot of the open draft (title, body, excerpt, SEO and Open Graph text, focus keyphrase, and any selected copy) to your configured Content Studio server so it can reply and suggest edits.
  • Current WordPress admin tab. The extension reads the active tab’s address only to detect whether you are on a WordPress admin page and to show a connected or disconnected toolbar icon. It does not keep a browsing history.

The extension does not collect health or financial information, does not use analytics or advertising SDKs, and does not sell data.

How data is stored

  • Host, access token, display name, user id, and public realtime connection settings returned at login (host, port, and app key — never the server secret) are stored in Chrome’s local extension storage on your computer. They are not synced through your Google account.
  • Short-lived login values (proof-of-login secrets, a one-time success message, and which editor tab is waiting for a chat reply) are stored in Chrome session storage and are cleared when you close the browser.
  • Chat transcripts stay in memory for the open editor page and are not written to disk by the extension.

How data is used

  • Sign you in to Content Studio and keep you signed in until you log out or the session expires.
  • Show your name or initials in the toolbar popup and chat overlay.
  • Send your prompt and draft snapshot to Content Studio so the assistant can suggest revisions.
  • Apply suggested edits to the open WordPress editor. The extension does not save or publish the post.
  • Show a login-success notification after you connect your account.

Where data is sent

The extension sends data only to the Content Studio origin you save in Settings, after Chrome asks you to allow that origin, and to the realtime host that server returns when you sign in (locally a port on that same machine, otherwise a ws. hostname of the same site). Save host asks Chrome for that expected realtime origin before login exists (localhost:8081, or ws. plus the hostname you entered). Typical requests are:

  • Sign-in (authorization code exchange) and sign-out
  • Your profile name for the avatar
  • Chat messages and the draft snapshot (HTTP kick-off)
  • A WebSocket to the realtime host returned at login so the assistant reply, suggested edits, and headline ideas can arrive without keeping a long HTTP request open
  • Channel authorization for that private chat connection

Your Content Studio server may use AI providers to generate replies, headline ideas, related images, or backlinks. Those downstream services are operated under Immediate Media’s Content Studio arrangements, not by the extension itself. The extension does not fetch third-party websites from your browser; if you paste a URL in chat, the server may retrieve that page.

The extension does not send your draft or chat to Google, advertisers, or other unrelated parties.

Third-party services

Chrome provides the sign-in window, local storage, and a background page used only to keep the realtime connection alive. The only application server the extension calls is the Content Studio host you configure, plus the realtime host that host returns at login. There is no analytics, crash reporting, or advertising network in the extension.

Data sharing

Immediate Media does not sell extension data. Draft and chat content is shared with the Content Studio service you connect to so the assistant can do its job. It is not used for credit scoring or for purposes unrelated to editing the open draft.

Data retention and deletion

  • Click Log out in the toolbar popup to remove the access token, display name, user id, and realtime settings from this browser. Changing the saved server host also clears those values.
  • Removing the extension from Chrome deletes its local storage.
  • Chat history on the editor page is discarded when you close or reload that tab.
  • How long Content Studio keeps server-side logs or chat records is governed by Immediate Media’s internal retention rules for that service, not by this extension.

Permissions in plain language

  • Tabs — detect a WordPress admin tab so the icon can show connected or disconnected.
  • Storage — remember your server, sign-in token, display name, user id, and realtime settings.
  • Identity — open the Content Studio sign-in window and return you to the extension.
  • Notifications — confirm a successful login after the sign-in window closes.
  • Offscreen documents — keep a quiet background page so chat replies can arrive after you send a message.
  • WordPress admin pages — show the revision overlay and read or update the open draft.
  • Optional access to the server you choose — requested only when you save a host, so chat, login, and the realtime connection can reach that origin and the matching realtime host (local port 8081, or ws. plus that hostname).

Changes to this policy

If the extension’s data practices change, this policy will be updated and the Chrome Web Store listing will be revised. The date at the top of this page shows the latest version.
